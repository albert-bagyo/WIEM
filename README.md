

# 🌦️ WIEM – Weather In Easy Manner 🌍

Welcome to **WIEM**, a lightweight and localized weather app designed to deliver **real-time forecasts in Twi** — one of Ghana's most widely spoken languages 🇬🇭.  
Built as part of the **Global Code Summer Program 2024**, this project combines **team collaboration**, **smart technology**, and **local impact**.

---

## 🚀 Overview

WIEM was built by a team of 4 with the goal of making weather information **accessible and relatable** to Ghanaians in their **native language**. Using **Flask**, **GhanaNLP**, **OpenWeather API**, and **MQTT**, the app delivers weather updates in real-time with natural-sounding Twi translations.

---

## 👨🏽‍💻 Tech Stack

- 🐍 **Python**
- 🌐 **Flask**
- 🗣️ **GhanaNLP** for Twi translations
- ☁️ **OpenWeather API** for real-time weather data
- 📡 **MQTT** for instant data communication
- 🖥️ **HTML/CSS/JS** for the frontend

## 📂 How to Run Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/albert-bagyo/wiem
   cd wiem
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the app:
   ```bash
   flask run
   ```

4. Open `http://127.0.0.1:5000` in your browser and enjoy! 🌍
